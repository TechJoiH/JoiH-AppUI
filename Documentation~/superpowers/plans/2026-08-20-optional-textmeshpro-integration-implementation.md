# Joi.H AppUI Optional TextMeshPro Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a release-ready `v0.4.0-pre.1` candidate that establishes a
formal boundary between AppUI base assemblies and UI-technology integrations,
with TextMeshPro as the first optional official integration.

**Architecture:** Keep one UPM package. Core, base Runtime, and base Editor
compile without TMP references; optional Runtime/Editor assemblies compile only
under `JOIH_APPUI_TMP`. Binding uses explicit Providers, Focus uses injected
Resolvers or explicit Dropdown Policies, and Notice uses an abstract view
contract with no fallback. Prove both modes in two cache-isolated Consumer
projects copied from one pristine template.

**Tech Stack:** Unity 6000.0.25f1, C# 9-compatible Unity compiler, UGUI 2.0.0,
Unity Test Framework/NUnit, PowerShell release tooling, UPM Git/local-path
installation, Mono and IL2CPP Windows builds.

**Spec:** `Documentation~/superpowers/specs/2026-08-20-optional-textmeshpro-integration-design.md`

## Global Constraints

- Official target remains Unity `6000.0`; do not create another official Unity line.
- Package ID remains `com.joih.appui`; do not create a second UPM package.
- Keep `com.unity.ugui: 2.0.0` as the only package dependency; do not add a
  separate TMP dependency.
- Core, base Runtime, base Editor, and base tests must contain no
  `TMPro`, `TMP_`, or `TextMeshPro` source/type references after migration.
- Optional integration compile symbol is exactly `JOIH_APPUI_TMP`.
- Binding Provider ID is exactly `joih.appui.tmp`.
- TMP InputField Resolver ID is exactly `joih.appui.tmp.input-field`.
- Do not add `IUIText`, `ITextLabel`, Resolver priority, reflection-based
  behavior discovery, automatic package installation, or automatic project mutation.
- `AppUINoticeVisualSettings.Enabled` defaults to `false`; no visual fallback
  may be created.
- Use TDD for every behavior change: record RED, implement the minimum, verify GREEN.
- Preserve public two-argument `AppUIRuntimeConfiguration` construction.
- Every new Unity-managed source, directory, asmdef, sample asset, and test asset
  must have a valid `.meta` generated by Unity or created with a unique GUID.
- Keep one tracked Consumer template only. Temporary Base/TMP Consumers live
  beneath an explicit validation RunRoot, are never added to Unity Hub, and are
  deleted after evidence collection.
- Do not move or rewrite `v0.3.0-pre.1`.
- Do not choose or add a public license in this change; licensing remains a
  separate publication decision.
